내 메뉴판, 직접 고치는 방법

가격이 바뀌었나요? 신메뉴가 나왔나요? 전화하지 않아도 점주님 휴대폰·컴퓨터에서 바로 고칠 수 있어요. 저장하면 약 1분 안에 손님 화면이 바뀌어요.

1이런 걸 직접 할 수 있어요

가격 바꾸기

메뉴 가격을 숫자만 고치면 끝. 크기별(소·중·대) 가격도 각각 고칠 수 있어요.

메뉴 추가·삭제·순서

새 메뉴·새 분류를 만들고, 필요 없는 메뉴는 지우고, ▲▼로 순서를 바꿔요.

사진 올리기

휴대폰 사진을 골라 올리면 알아서 크기를 줄여 줘요. 분류 배너 사진, 메뉴 옆 사진 모두 가능해요.

설명·표시

메뉴 설명을 적고 BEST·신메뉴·추천 표시와 매운 메뉴 표시를 붙여요.

가게 정보

전화번호·주소·와이파이를 바꿔요. 와이파이를 넣으면 손님 화면에 "복사" 버튼이 생겨요.

되돌리기

실수해도 괜찮아요. 이전에 저장한 버전으로, 또는 처음 메뉴로 되돌릴 수 있어요.

2로그인

  1. 우리가 보내 드린 주소를 열어요. 가게 아이디가 이미 들어 있어요.
  2. 비밀번호를 넣고 [들어가기]를 눌러요.
  3. 다 끝나면 오른쪽 위 [나가기]. 안 눌러도 12시간 뒤에는 자동으로 로그아웃돼요.
비밀번호는 가게마다 따로 만들어 한 번만 알려 드려요. 잊어버렸거나 다른 사람이 알게 됐다면 바로 연락 주세요. 새로 만들어 드려요. 비밀번호를 연속으로 틀리면 한 시간 동안 로그인이 막혀요.

3화면 둘러보기

빨간 번호가 아래 설명의 번호예요. 모든 칸은 한국어·베트남어 두 칸에 직접 써 주세요.

  1. 1저장하고 손님 화면에 반영 — 고친 뒤 꼭 눌러야 해요. 누르기 전에는 손님 화면이 바뀌지 않아요.
  2. 2저장 상태 — "저장하지 않은 변경이 있어요"가 주황색으로 보이면 아직 저장 전이에요.
  3. 3이전 버전 — 저장한 기록 목록이 나와요. 원하는 시점의 [이 버전으로]를 누르면 되돌아가요.
  4. 4처음 메뉴로 되돌리기 — 고친 내용을 모두 지우고 처음 메뉴로 돌아가요(이전 버전 기록은 남아요).
  5. 5입력 안내 — 한국어·베트남어 두 칸에 직접 써 주세요.
  6. 6메뉴 분류 — 분류 이름·배너 사진·순서(▲▼)·삭제. 분류 안에 메뉴가 들어 있어요.
  7. 7메뉴 사진 — 메뉴 이름 옆에 작게 보이는 사진이에요.
  8. 8메뉴 이름 — 한국어 칸과 베트남어 칸.
  9. 9가격 — 숫자만 써요(예: 150000). 비워 두면 손님 화면에 "가격 문의"로 나와요. 크기별 가격 메뉴는 크기마다 가격 칸이 나와요.
  10. 10사진 올리기·지우기, ▲▼ 순서, 삭제 — 삭제는 확인 창이 한 번 더 떠요.
  11. 11더 보기 — 눌러서 펼치면 아래 그림처럼 설명·표시가 나와요.

3-2[더 보기]를 펼치면

  1. 12설명(선택) — 메뉴 소개나 안내를 짧게 써요(예: "2~3인분", "오늘 품절").
  2. 13표시 — 없음 / BEST / 신메뉴 / 추천 중에서 골라요. 손님 화면에 작은 표시가 붙어요.
  3. 14매운 메뉴 — 체크하면 손님 화면에 매운맛 표시가 붙어요.
  4. 15다른 언어로 보이는 글자 — 영어·중국어·일본어 손님이 보는 글자예요. 비워 두면 저장할 때 자동 번역을 시도하고, 직접 써 두면 그 글자가 그대로 보여요.

4이럴 땐 이렇게

하고 싶은 일방법
가격 바꾸기메뉴를 찾아 가격 칸(9)의 숫자를 고쳐요 → 맨 위 [저장하고 손님 화면에 반영](1).
새 메뉴 넣기그 분류 맨 아래 [+ 메뉴 추가] → 이름(한국어·베트남어)과 가격 입력 → 필요하면 [사진 올리기] → 저장. 이름이 비어 있는 메뉴는 저장할 때 빠져요.
메뉴 지우기·순서 바꾸기그 메뉴의 [삭제](확인 창에서 한 번 더) 또는 ▲▼ → 저장.
새 분류 만들기화면 맨 아래 [+ 분류 추가] → 분류 이름 입력 → 그 안에 [+ 메뉴 추가].
사진 올리기·바꾸기[사진 올리기] → 휴대폰 사진 선택(자동으로 줄여서 올라가요) → 저장. 지우려면 [사진 지우기].
신메뉴 알리기[더 보기] → 표시를 신메뉴로. 손님 화면에 NEW 표시가 붙어요. 인기 메뉴는 BEST, 추천 메뉴는 추천.
오늘만 못 파는 메뉴[더 보기] 설명 칸에 "오늘 품절"처럼 적고 저장. 다시 팔 때 지우면 돼요.
전화·주소·와이파이맨 위 가게 정보 칸을 고치고 저장. 와이파이 이름·비밀번호를 넣으면 손님 화면 아래에 와이파이 복사 버튼이 생겨요.
실수했을 때저장 전이면 페이지를 새로 고침하면 처음 상태로 돌아가요. 저장했다면 [이전 버전](3)에서 되돌리거나 [처음 메뉴로 되돌리기](4).

5알아 두세요

저장 → 약 1분 뒤 반영

  • 저장하면 손님 화면에는 약 1분 안에 바뀌어요.
  • 저장하지 않고 창을 닫으면 고친 내용이 사라져요(닫기 전에 경고가 떠요).
  • 화면이 비어 보이면 새로 고침을 한 번 눌러 주세요.

번역은 이렇게 돼요

  • 한국어·베트남어는 쓰신 그대로 보여요.
  • 영어·중국어·일본어 자동 번역 연결은 준비 중이라, 지금은 직접 써 주시면 가장 정확해요(15번 칸).
  • 비워 두면 입력한 글자가 그대로 보일 수 있어요.

사진 팁

  • 음식이 크게 나온 밝은 사진이 좋아요.
  • 너무 큰 파일은 올라가지 않을 수 있어요. 그럴 땐 다시 찍거나 줄여서 올려 주세요.
  • 사진은 메뉴 옆에 작고 동그랗게 보이고, 누르면 크게 보여요.

안전하게 쓰기

  • 비밀번호는 점주님과 직원 중 꼭 필요한 분만 알아 두세요.
  • 공용 컴퓨터에서는 쓰고 나서 [나가기]를 눌러요.
  • 가격 칸을 비우면 "가격 문의"로 나와요. 일부러 비울 때만 비워요.

6방문 리포트 — QR 메뉴판을 몇 명이 봤을까?

우리가 점주님께 전용 링크를 보내 드려요. 비밀번호 없이 열리고, 휴대폰에서도 보기 좋고, [인쇄 / PDF로 저장]도 돼요.

방문자·페이지뷰

기간(기본 30일) 동안 몇 명이 메뉴판을 열었는지. 같은 분이 하루에 여러 번 열어도 1명으로 세요.

하루 평균·가장 많이 온 날

하루 평균 방문자와 가장 붐빈 날을 한눈에 볼 수 있어요.

일별 방문자 그래프

요일·행사 뒤에 손님이 늘었는지 날마다 확인해요.

손님이 본 언어

한국어·베트남어·영어·중국어·일본어 중 어떤 언어로 봤는지. 메뉴 번역을 챙길 때 참고해요.

접속 기기

휴대폰으로 본 손님과 컴퓨터로 본 손님의 비율.

어디서 들어왔나

테이블 QR을 찍고 왔는지, 가게 찾기·검색에서 왔는지. 우리 가게 방문은 기록하지 않도록 설정할 수 있어요.

로봇(검색엔진 등)은 빼고 세요. 날짜는 베트남 시간 기준이에요. 이미 인쇄해서 쓰고 있는 QR 카드는 "직접·QR"로 모여요.
