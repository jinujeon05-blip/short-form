# 등불 마을 이야기: AI illustration prompts (Google Flow)

The game picks these files up automatically. Save each image in this folder
(`rpg-demo/art/`) with the exact file name below. A missing file keeps the
built-in pixel art, so you can add them one at a time.

Use the same style line at the start of every prompt so the set matches:

> Style: painterly 2D fantasy RPG illustration, warm lantern light against a
> dusky violet night, soft rim lighting, rich but muted colors, clean
> linework, Korean fantasy village setting, no text, no watermark.

Optional extra (not wired into the game yet): `boss-golem.png`, 16:9: a towering
shadow golem made of dark violet stone with glowing purple cracks and eyes,

Tips:
- Square portraits read best at 512×512 or larger. Keep the face centered.
- Export PNG. If Flow gives JPG, rename the extension only if the game page
  still loads it; otherwise convert to PNG.
