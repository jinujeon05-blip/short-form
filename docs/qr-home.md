## 메뉴판 왼쪽 위 "QR MENU" 로고 (모든 메뉴판, 사용자 지시 2026-10-22)
- 모든 메뉴판(정식·가게 찾기용) 맨 위 **왼쪽 구석**에 **글자 없이 "QR MENU" 로고만** 든 **동그란 버튼**(29px)을 붙이고, 누르면 가게 찾기 페이지(`https://qrmenuasia.com/stores/?lang=<언어>`)가 새 탭으로 열린다. **색은 가게 테마를 따른다**: 바탕 = 그 가게 `partner-theme`의 `--pt-btn`(버튼색, 그라데이션도 됨), 로고 = `--pt-btn-ink`, 흰 테두리 + 그림자로 어떤 사진·배경 위에서도 보인다. 오른쪽 위 언어 버튼과 같은 높이·위치(위 10px)라 좌우 짝을 이룬다(34곳 캡처로 확인). 사용자 판단: 글자가 없어야 사람들이 홈 버튼처럼 눌러 본다(처음 만든 주황 네모·그다음 '가게 더 보기' 글자가 든 알약은 둘 다 바꿈).
- 원본 `restaurants/_shared/qr-home.js`·`qr-mark.png`(소개서 아이콘 `sales/icons/icon-512.png`에서 글자 'QR MENU'만 한 가지 색 마스크로 뽑은 `qr-mark.png` 128px — CSS mask로 가게 색을 입힘) 하나, `restaurants/_shared/sync-home.sh`로 복사(대상은 `sync-lang.sh`의 SHOPS 전체, `qr-home.js`·`qr-mark.png`) + `lang-menu.js` 다음에 `<script src="qr-home.js">`가 들어간다. 새 가게는 `sync-lang.sh` SHOPS에 넣으면 같이 처리된다. `node tools/check-listing.mjs`가 가게 찾기용 전체에 이 로고가 있는지 검사한다.
- **홈 화면 아이콘의 지구본 모양**: 우리 아이콘 파일(`sales/icons/`)에는 지구본이 없다. 삼성 인터넷이 '웹앱으로 설치'할 수 없는 페이지를 홈 화면에 추가하면 자기 로고(파란 행성)를 아이콘 모서리에 배지로 붙인다. 소개서(`/`)·가게 찾기(`/stores/`)에 최소 서비스 워커 `sales/sw.js`(요청을 그대로 통과, 저장 안 함)와 등록 코드를 넣어 '웹앱 설치'가 되게 했다(`<!-- sw:start/end -->`). 기존 바로가기는 삭제하고 새로 추가해야 바뀐다. **결과(2026-10-22)**: 배포 후 사용자가 삼성 인터넷에서 새로 추가했는데 **지구본(삼성 인터넷 행성) 배지가 그대로 나왔다.** 서버 쪽은 정상이다 — 배포된 `/sw.js`·`/stores/manifest.webmanifest`(application/manifest+json, 아이콘 192·512·maskable) 확인, 크롬 `Page.getInstallabilityErrors` 오류 없음(소개서·가게 찾기 모두). 즉 우리 쪽에서 고칠 게 남아 있지 않아 보이고, 삼성 인터넷이 홈 화면에 추가한 아이콘에 자기 배지를 붙이는 동작으로 추정(미확인). 크롬에서 '앱 설치'로 추가하면 배지가 없을 수 있음 — 사용자 확인 대기. 같은 일을 다시 시도하지 말 것(서비스 워커·manifest는 이미 있음). 가게 메뉴판 자체에는 웹앱 설정이 없다(손님이 가게를 홈 화면에 추가할 일이 적고, 우리 아이콘으로 바뀌면 안 되므로).
