- 입력: 드라이브 `QR메뉴판/바보아저씨/menu_01.jpg`(사본을 스크래치에 받음). 배포·수정 없음.
- 담당: menu-reader 지시서를 sonnet에 넘겨 실행. **새 담당 파일은 세션 시작 때만 등록돼서** 이 세션에서는 이름(`menu-reader`)으로 못 부름 → 다음 세션부터 이름으로 부른다.
- 결과: 지금 `restaurants/babo/menu.js`와 비교해 **67개 메뉴 이름·가격 전부 일치**, 가격 없는 안주 6개도 '없음'으로 맞음. 누락 0, 틀림 0.
- 작은 결함: 분류별 줄 수를 66으로 잘못 셈(분식 10개를 9개로) → 지시서에 '표의 줄을 다시 세기' 추가.
- 사용량: 담당 약 8만 토큰(사진 1장, 확대 2장).
- 미검증: 사진 4~6장 고르기(finder), 번역 규칙(polisher), 새 reviewer 순서 — 다음 실제 가게에서 확인.
