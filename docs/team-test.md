## 시험 4: 안티그래비티 CLI로 메뉴판 읽기 (합격, 2026-10-27)
- 제미나이 CLI는 2026-06-18부터 Pro 로그인 불가 → 안티그래비티 CLI `agy` 1.4.7 설치(`%LOCALAPPDATA%\agy\bin\agy.exe`, PowerShell `irm https://antigravity.google/cli/install.ps1 | iex`). 이미 구글 로그인돼 있어 로그인 창 없음. 비용 0(Pro 구독).
- 클로드(로컬 세션)가 `agy -p`를 불러도 멈추지 않음(윈도우에서 멈춘다는 보고 antigravity-cli#318은 이번엔 안 생김).
- 바보아저씨 `menu_01.jpg` → 약 1분에 67줄 표. `menu.js`와 비교: **개수 67=67, 가격 67개 전부 일치**, 이름 53개 글자까지 같고 14개는 괄호 설명·'1pcs/1pc'·'or/또는' 차이뿐. 저장소 파일 변경 없음(계획 모드).
- 결론: PC 세션에서는 메뉴판 읽기를 agy에 먼저 맡긴다. 클로드 쪽 토큰은 메인 대조분만 든다(구글 쪽 사용량은 세션에서 안 보임).
- 아직 안 해 본 것: 메뉴판 여러 장·흐린 사진·베트남어 메뉴판.

## 안티그래비티로 가격 재대조 시험 (2026-10-30, 운영 감찰관을 코덱스 대신 agy로)
- `agy models`: Gemini 4 Argon·3.8 Flash 말고도 **Claude Opus 5.5·Sonnet 5.5, GPT-OSS 120B**가 있다. 이것들은 Claude Pro 한도가 아니라 안티그래비티 한도를 쓴다.
- 시험: 어수사 메뉴판 5장(`.scratch/eosusa/menus/menu_01~05.jpg`, 이미 줄인 것) + 검수한 표에 **일부러 틀린 값 2개**(도미 회 소 880,000→860,000, 우동 150,000→170,000).
  - `--model gpt-oss-120b-medium`: **"사진 못 봄"**(글자 전용 모델, 10초). 가격 재대조에 못 씀.
  - `--model claude-sonnet-5-5-medium --mode plan`: 1차는 사진을 명령 도구로 열려다 막힘("command permission … auto-denied"). 2차에 "명령 도구는 쓰지 말고 파일 보기 도구로만 열어"를 넣자 **30초에 도미 회 틀린 값을 찾음**(우동은 이 5장에 없어 언급 없음 = 맞음). 행사가(힐링 SALE)·'시세' 스티커도 따로 짚음.
- 지시문에 "명령(command·터미널) 도구는 절대 쓰지 말고, 파일 보기 도구로만"을 꼭 넣는다. 규칙(CLAUDE.md 5장) 반영은 사용자 결정 대기.
- **사용자 결정 '다-1'(2026-10-30)로 운영 감찰관 = 안티그래비티 안 Claude Sonnet**(CLAUDE.md 5장·대시보드 `ORDER_RULES` 반영). 대시보드 실제 지시 시험(1030-204404): 비서실장이 `agy --mode plan --model claude-sonnet-5-5-medium` 명령을 막힘 0개로 돌림, 5장 대조 18초, 사무실에서 운영 감찰관 자리로 잡힘(`worked: claude, codex`). 토큰은 비서실장 쪽 약 11만(다시 읽은 것 포함, 시험 지시 한 번 기준) — 재대조 자체의 Claude 한도 사용은 0.

## 안티그래비티 코드 작성 시험 (2026-10-31, 점주 화면 기능)
- `agy --mode accept-edits --print-timeout 840s -p "명령(터미널) 도구는 절대 쓰지 말고 파일 보기·편집 도구로만 … 지시서를 읽고 구현, 지시서 파일 외엔 고치지 마"` → **합격**. 지시서 6개 파일만 고침, 약 5분.
- 클로드 검토에서 고친 것 2가지: 품절 체크가 '더 보기' 안에 숨음(점주가 못 찾음) · 영업시간 칸이 없는 옛 가게에도 입력칸이 보임. → 지시서에 "점주가 자주 누르는 것은 바로 보이게", "가게마다 다른 경우" 를 미리 적으면 줄어든다.
- 방식: 클로드가 코드를 읽고 지시서(파일·필드·문구·보안 조건)를 자세히 쓴다 → agy 구현 → 클로드가 diff 검토·로컬 시험·캡처.
