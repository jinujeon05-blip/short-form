## 1. 절대 금지 사항 (재발 방지)
1. **CSS 크기 키웠다 줄였다(`scale` 숨쉬기 등) 눈속임 애니메이션 절대 금지**
   - 캡틴은 정지 이미지를 CSS로 늘렸다 줄였다 하는 가짜 움직임을 싫어한다. 상태창 캐릭터 움직임은 반드시 **실제 생성 영상(`.mp4` / `.webm`)**으로 적용한다.
2. **영상 AI(Gemini Veo · Kling · Flow)에 '턴어라운드 시트 + UI 버튼이 있는 상태창 캡처' 2장을 같이 넣지 않는다**
   - **실수 기록 (2026-11-28)**: 턴어라운드 시트와 UI 상태창 캡처 2장을 같이 넣어 Veo 영상을 생성했더니, AI가 카메라를 허리 위로 줌인해 다리·구두가 잘리고 배경 비율이 상태창(`status-bg-pc.png`)과 완전히 어긋났다.
3. **캐릭터 외형 임의 변형 절대 금지**
   - 얼굴, 안경, 헤어스타일, 상의, 사원증, 치마, 스타킹, 구두, 소품(클립보드 등)이 영상 도중 단 1%라도 바뀌면 불합격.

## 2. 정석 제작 절차 (모든 직원 공통)

### 단계 A: 16:9 단일 기준 첫 프레임 이미지 생성 (필수)
- 배경: `dashboard/static/office-anime/assets/status-bg-pc.png` (`1672×941`, UI 상자·버튼·글자 **완전 제거된 순수 배경**)
- 캐릭터: `dashboard/static/office-anime/assets/walk/<id>-front-1.webp` (투명 배경 전신 정면)
- 정확한 합성 위치:
  - 가로: 정중앙 (`x = (W - target_w) // 2`)
  - 세로: 머리 꼭대기 `y = 15.5%`, 전신 높이 `target_h = 70.0%` (구두 끝이 바닥 황금 타원 러그 정중앙 `85.5%`에 정확히 안착)
- **영상 AI에는 반드시 이 단일 16:9 PNG 1장만 첨부**한다 (2장 첨부 금지!).

### 단계 B: 영상 생성 프롬프트 필수 포함 조건
1. **카메라 완전 고정**: `100% STATIC LOCKED TRIPOD CAMERA. ZERO zoom, ZERO pan, ZERO tilt, ZERO camera movement.`
2. **배경 완전 정지**: `The entire office background, windows, desk, plants, and golden oval floor rug must remain 100% frozen and unchanged.`
3. **외형 100% 고정**: `Preserve the EXACT character face, glasses, hair, outfit, skirt, stockings, and shoes from frame 1 without ANY alteration.`
4. **자연스러운 2단 동작 구성** (5초~8초 영상 1편을 2가지 동작으로 자연스럽게 연결해 앞/뒤 2가지 용도로 분할 사용 가능):
   - **전반부 (0~4초 · 대기/응대 동작)**: 황금 러그 위 제자리에 서서 자연스럽게 눈 깜빡임, 부드러운 호흡, 머리카락 미세 흔들림, 한 손으로 안경 또는 클립보드를 살짝 고쳐 잡으며 차분한 미소.
   - **후반부 (4~8초 · 대화/안내 동작)**: 같은 자리에 그대로 선 채 한쪽 손을 우아하게 들어 올려 안내 제스처를 취하며 고개를 살짝 끄덕이고 환하게 미소 지은 뒤 자연스럽게 원래 자세로 복귀.

### 단계 C: 상태창 적용 및 검증
- 생성된 영상은 배경(`status-bg-pc.png`)과 픽셀 단위로 완벽히 겹치므로, 상태창 배경 레이어 위에 `<video autoplay loop muted playsinline>`로 재생하면 **좌측 대화창·우측 버튼과 100% 자연스럽게 합쳐진다**.
- 적용 완료 보고 전 반드시 **Playwright로 상태창을 열어 실제 샘플 캡처를 찍어 확인**한 뒤 보고한다.
