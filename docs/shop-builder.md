# 운영자 모드 '가게 만들기' (2026-11-13, 캡틴 결정 가-1·나-1·다-1·라-1)

> 캡틴이 대시보드(127.0.0.1:8899, 폰 8900)의 가운데 탭 **'가게 만들기'**에서 가게 하나를 처음부터 끝까지 직접 만든다.
> 화면은 앞단일 뿐이고, 실제로 만드는 것은 저장소 도구(`new-shop` → `register-shop` → `check-shop`)다. 구조는 가마솥 표준 그대로.

## 캡틴 사용법 (화면 순서)
1. 대시보드 → 가운데 탭 **가게 만들기** → 가게 id(영문 소문자, 주소가 됨)·종류(가게 찾기용/정식) → **이 id로 시작**.
2. 왼쪽 칸 1~8을 채운다. 쓰는 대로 자동 저장된다(다른 가게로 갔다 와도 '이어서 하기'로 다시 열림).
   - ① 이름(한국어·영문) ② 맨 위 그림(로고 PNG 또는 간판 사진 → 16:9로 자르기 창) ③ 색 묶음 고르고 색 바꾸기
   - ④ 한 줄 소개·특징 칩·인사 문구 ⑤ 전화·주소·구글 지도 주소·영업시간·와이파이
   - ⑥ 음식 사진(여러 장 한 번에 → 장마다 4:3 자르기 창, 640×480 JPEG) ⑦ 메뉴(분류·이름·가격·시가·크기별 가격·BEST·매운·사진·설명)
   - ⑦ **표로 한꺼번에 넣기**: `분류 | 메뉴 이름 | 가격` 줄을 붙여 넣으면 메뉴가 들어간다(안티그래비티 메뉴판 읽기 결과 그대로). 가격 `150,000`·`시가`·`S 100000 / L 150000`.
   - ⑧ 가게 찾기 등록 정보(지역·분류·표시·가게 종류 한 줄·요리 종류 영문)
3. **AI 번역으로 빈 칸 채우기**: 한국어가 있는 칸의 빈 번역(en·zh·ja·vi)만 채운다. 채운 칸은 노란색 'AI 초안' — 고치면 표시가 사라진다. 영문 이름이 비어 있으면 로마자로 채운다.
4. **① 미리 만들기** → 오른쪽에 폰 화면(언어·폰/PC 바꾸기, 새 창으로 열기). 빠진 칸이 있으면 빨간 글씨로 무엇이 비었는지 나온다.
5. **② 저장·점검** → 등록(가게 찾기 목록·검색·카드 사진·방문 기록, 정식이면 QR·테이블 카드·SNS 이미지) + `check-shop`. 1~3분.
6. **③ 커밋하고 결재함에 올리기** → 결재함에 '배포 대기' 카드(폰 캡처 포함). 배포는 결재함 **[배포 확정]**(기존 흐름 그대로).
- 등록 전에는 '이 초안 지우기'(초안 + 미리 만든 폴더만, 확인 창에 지울 것이 나옴). 등록한 뒤에는 화면에서 못 지운다 → Claude 앱에 "<id> 가게 만들기 취소해줘".
- 등록한 뒤에도 메뉴·색·문구를 고치고 ①·②를 다시 누를 수 있다. **등록 정보(⑧·이름)는 처음 등록한 값이 남는다**(register-shop 이 '이미 있음'은 건너뜀) — 바꾸려면 Claude 앱에서.
- 커밋한 뒤에는 화면이 잠긴다. 고칠 것은 Claude 앱이나 점주 편집 화면.

## 구조
- 화면 `dashboard/static/builder.js`·`builder.css`(탭 `#tab-builder`) → 서버 `dashboard/builder.py`(`/api/builder/*`, `server.py`가 불러 씀) → 도구 `tools/build-shop.mjs`.
- 초안: `dashboard/out/builder/<id>/draft.json` + `img/`(git 제외). 상태 `state.json`(built → registered → checked → committed), 이 화면으로 만든 표시 `built.json`.
- `build-shop.mjs <id> <초안폴더> build`: `new-shop.mjs` 후 색(`:root`·파트너 배너)·이름·5개 언어 문구·`menu.js`·사진을 채운다. 가마솥 모양(왼쪽 띠·물결·모서리 선)은 빼고 위쪽 띠로(CLAUDE.md 2장). `RESTAURANT.mapUrl`이 있으면 지도 버튼이 그 주소로.
  - 다시 만들기는 **커밋 안 됐고 `built.json`이 있는 폴더만** 지우고 새로 만든다. 이미 있는 가게 id는 거절.
- `build-shop.mjs <id> <초안폴더> register`: `register.json`을 만들어 `register-shop.mjs`. 정식이면 `qr.cjs`(+`qr-check.py` 확인)·기본 테이블 카드(`print/table-card.html`, 가게 색·맨 위 그림) → `card.mjs`·`sns.mjs`. 더 예쁜 카드는 designer 담당에게.
- `--meta`: 지역·분류·표시 목록과 이미 있는 가게 id.
- 미리보기 주소 `/shop/<id>/…`(restaurants/<id> 안 파일만), 초안 사진 `/builder-img/<id>/<사진>`. 사진 올리기만 POST 크기 6MB까지(그 밖 API는 예전처럼 1만 바이트).
- 번역: `agy --mode plan -p`(저장소 밖 빈 폴더 `dashboard/out/builder/_translate`에서) → 실패한 칸만 `claude -p --model sonnet`(도구 금지). 둘 다 AI 실행 환경에서 비밀값(`SECRET_ENV`)·API 키를 뺀다. 60칸·3500자씩 나눠 보낸다. 한 번에 하나.
- 저장·점검 전에 등록이 고칠 공통 파일(`REG_FILES`)에 다른 작업의 커밋 안 한 수정이 있으면 멈춘다(커밋 때 남의 변경이 섞이지 않게).
- 커밋은 `restaurants/<id>`·`sales/img/demo-<id>.jpg`·`REG_FILES`만. 전체 사이트맵은 **이 가게 줄만** 남기고 다른 줄은 커밋된 값으로 되돌린다(seo.mjs 가 다른 가게 날짜까지 바꾸던 것, 시험에서 19줄).
- 결재함 카드는 지시와 같은 모양(`status: done`, `deploy: [id]`, `via: builder`)이라 기존 `run_deploy`가 그대로 돈다.
