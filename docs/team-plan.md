## 일하는 방식 (모든 세션 공통)
- **확인하지 않은 것을 "됐다"고 하지 않는다.** 실제로 열어 보거나 실행해 본 것만 완료로 쓰고, 나머지는 맨 앞에 '미확인'.
- 사용자가 할 일은 **한 단계씩** 화면 기준으로 적는다(클릭할 곳 → 확인할 것).
- 사용자가 지시하지 않은 범위(폰 접속, 새 포트, 다른 프로그램 끄기 등)로 넓히기 전에 먼저 묻는다.
- 로컬 PC 폴더에서는 작업 전 `git status`로 상태를 보고, 끝나면 커밋해서 폴더를 깨끗하게 둔다. 다른 프로그램(서버 등)을 끄거나 켤 때는 무엇을 끄는지 먼저 말한다.
