## 목표
이미 있는 로컬 대시보드 'Jinwoo 에이전트'(http://127.0.0.1:8899)에 **'영업' 탭을 하나 추가**한다. 캡틴이 배포된 가게 사장님께 Zalo 영업 메시지를 '반자동'으로 보내게 돕는 화면이다.

흐름: 가게 목록 → [메시지 만들기] → 한국어·베트남어 초안 → [복사] + [Zalo 열기](그 가게 전화번호로 Zalo 대화창) → 캡틴이 직접 붙여 넣고 보냄 → [보냄 표시]를 누르면 날짜가 기록됨 → 보낸 지 3일 넘었는데 답 없음 표시가 된 가게는 위로 올라옴.

## 먼저 읽을 파일 (읽기만)
1. `CLAUDE.md` — 이 저장소의 규칙. 특히 2장 '절대 규칙'
2. `docs/dashboard.md` — 대시보드 구조·지난 변경 이유
3. `docs/gem-sales.md` — 영업 메시지 규칙(가격·연락처·말투·금지사항). 메시지 만들기는 이 규칙을 그대로 쓴다
4. `dashboard/server.py` — 서버(파이썬 표준 라이브러리만 사용). `do_GET`·`do_POST`의 `/api/...` 경로, `build_stores()`(가게 목록), `cached()`, `write_atomic()`, `sh()`
5. `dashboard/static/index.html`·`app.js`·`style.css` — 화면. 탭은 `data-tab`(가게 현황·팀 대화·할 일·방문 기록·사용량·가게 만들기)
6. `restaurants/<가게>/menu.js` — 가게 전화(`phone:`), 이름(`brand: { ko, en }`)
7. `docs/stores.md` — 가게가 정식인지 가게 찾기용인지
8. `git log --oneline -15 -- dashboard/`

## 1단계: 조사·계획만 (파일을 고치지 않는다)
아래를 확인하고 표로 보고한 뒤 **멈추고 캡틴의 답을 기다린다.**
1. 메시지 초안을 **추가 비용 0원으로** 만들 방법: 이 PC의 안티그래비티 CLI(`agy -p`, 계획 모드, 제미나이 모델)를 대시보드 서버가 불러 쓸 수 있는지 실제로 한 번 돌려 본다. API 키가 필요한 방법(제미나이 API 등)은 쓰지 않는다. Claude(`claude -p`)도 쓰지 않는다(한도를 아끼려고).
2. 가게마다 필요한 값(한글 이름·영어 이름·주소 `https://<가게>.qrmenuasia.com`·전화·정식/가게 찾기용)을 어디서 읽을 수 있는지. 값이 없는 가게 수.
3. `https://zalo.me/<전화번호 숫자만>` 주소가 Zalo 대화창을 여는지(PC 브라우저에서 확인 가능한 만큼).
4. 추가할 것과 바꿀 것 목록: 새 파일, 새 `/api/...` 경로, 바뀌는 기존 파일과 그 부분. **지우거나 바꾸는 기존 기능이 있으면 따로 표시**한다.
5. 남은 위험과 모르는 것.

보고 끝에 "2단계로 진행할까요? 가-1 진행 / 가-2 고칠 점 있음" 처럼 번호 보기로 묻는다.

## 2단계: 만들기 (캡틴이 "2단계 진행"이라고 한 뒤에만)
- 기존 탭·기능은 그대로 둔다. 새 탭 `data-tab="sales"`만 더한다.
- 서버 새 경로 예시: `GET /api/sales`(목록), `POST /api/sales/draft`(초안 만들기), `POST /api/sales/sent`(보냄 표시). 기존 보안(Host 확인·`X-Dashboard` 헤더)을 그대로 따른다.
- 기록 파일은 `dashboard/out/sales-log.json`(git 제외 폴더), 저장은 반드시 `write_atomic()`으로 한다.
- 초안을 만드는 중에 화면이 멈추지 않게 한다(기다림 표시, 실패하면 이유를 글로 보여 줌).
- 화면은 PC 폭과 폰 폭(375px) 둘 다에서 잘림·넘침이 없어야 한다.
- `docs/dashboard.md` 끝에 '영업 탭 (날짜)' 칸을 만들어 무엇을 왜 만들었는지 적는다.

## 3단계: 시험
- **지금 켜져 있는 대시보드(8899)는 끄지 않는다.** 시험은 `DASH_PORT=8911`로 따로 켠 서버에서 하고, 끝나면 그 서버만 끈다.
- 실제 순서대로 시험한다: 탭 열기 → 가게 하나 초안 만들기 → 복사 → Zalo 열기 주소 확인 → 보냄 표시 → 서버 껐다 켜도 기록이 남는지.
- PC 폭·폰 폭 화면 캡처를 직접 보고 확인한다.
- 실제 사장님께 아무것도 보내지 않는다.

## 절대 지킬 것
- **메시지를 자동으로 보내는 기능은 만들지 않는다.** 보내기는 항상 캡틴이 Zalo에서 직접 한다.
- 돈이 드는 것(유료 API·구독·Zalo 공식 계정 요금)은 쓰기 전에 멈추고 묻는다.
- 비밀번호·토큰·환경변수 값은 읽지도, 출력하지도, 파일에 적지도 않는다.
- 다른 가게 폴더(`restaurants/`), `sales/`, `tools/`는 고치지 않는다. 고치는 곳은 `dashboard/`와 `docs/dashboard.md`뿐이다.
- `git push`, `git merge`, 배포(Vercel)는 하지 않는다. **커밋도 캡틴이 "커밋해"라고 한 뒤에만** 한다.
- 실패하면 2번까지만 고쳐 보고, 그래도 안 되면 원인·남은 일·추천을 한 줄로 보고한다.
- 확인하지 않은 것은 '됐다'고 하지 않고 '미확인'이라고 쓴다.
