# 3D 사무실 캐릭터 직접 고치기 (캡틴용, 2026-11-22)

> 고치는 파일은 하나뿐입니다: `D:\qrmenu\dashboard\static\office-3d\office-3d.js` 맨 위 `CHARS` 표.
> 서버를 다시 켤 필요는 없습니다. **저장 → 3D 사무실 화면에서 F5**만 누르면 바로 바뀝니다.

## 1. 파일 열기 (메모장, 설치 필요 없음)
1. 키보드에서 `윈도우 키 + R`을 누릅니다.
2. 아래를 그대로 붙여 넣고 Enter를 누릅니다.
   `notepad D:\qrmenu\dashboard\static\office-3d\office-3d.js`
3. 위에서 15번째 줄 근처에 `★ 캐릭터 꾸미기는 여기만 고치면 된다`가 보입니다. 바로 아래 10줄이 사람 10명입니다.

## 2. 한 줄 읽는 법 (비서실장 예)
```
claude: { name: '비서실장', short: '비서실장', role: '지휘', home: [50.0, 36.0], face: 's',
          body: 'woman', hair: 'long', hairC: 0x2b1d14, suit: 0x3a3f47, pants: 0x30343b, tie: null },
```
| 칸 | 뜻 | 넣을 수 있는 값 |
|---|---|---|
| `name` | 이름표(PC) | 아무 글 |
| `short` | 이름표(폰, 짧게) | 아무 글(4글자 이하 추천) |
| `body` | 몸 | `'man'` 남자 · `'woman'` 여자 |
| `hair` | 머리 모양 | `'simpleparted'` 옆 가르마 · `'buzzed'` 짧은 머리 · `'long'` 긴 머리 · `'buns'` 올림머리 |
| `hairC` | 머리 색 | `0x` + 색 번호 6자리 |
| `suit` | 자켓 색 | `0x` + 색 번호 6자리 |
| `pants` | 바지 색 | `0x` + 색 번호 6자리 |
| `tie` | 넥타이 색 | `0x` + 색 번호, 또는 `null`(넥타이 없음, 여자는 자동으로 없음) |

## 3. 색 번호 찾기
1. 구글에서 `color picker`를 검색합니다(구글 색 고르기 상자가 나옵니다).
2. 원하는 색을 고르면 `HEX`에 `#1f2f5c` 같은 값이 보입니다.
3. `#`을 빼고 앞에 `0x`를 붙여 넣습니다. 예: `#1f2f5c` → `0x1f2f5c`

자주 쓰는 색: 남색 `0x1f2f5c` · 검정 `0x1a1a1a` · 회색 `0x55595f` · 흰색 `0xf3f1ec` · 빨강 `0x8b1a2b` · 베이지 `0xc8b391` · 갈색 머리 `0x5a3a22` · 검은 머리 `0x15120f`

## 4. 저장하고 보기
1. 메모장에서 `Ctrl + S`로 저장합니다.
2. 크롬의 `127.0.0.1:8899/static/office-3d/index.html` 창에서 `F5`를 누릅니다.
3. 화면이 **"3D 사무실 불러오는 중…"에서 멈추면** 쉼표·따옴표가 하나 빠진 것입니다. 메모장에서 `Ctrl + Z`로 되돌리고 저장 → F5.

## 5. 주의
- 바꾸는 곳은 작은따옴표 `'...'` 안의 글자와 `0x...` 숫자뿐입니다. 쉼표 `,`·중괄호 `{ }`는 지우지 않습니다.
- `home`·`face`(자리·방향)를 바꾸면 책상도 같이 움직입니다. 자리끼리 겹칠 수 있으니 바꾼 뒤 화면을 꼭 봅니다.
- 다 고친 뒤 "캐릭터 고쳤어"라고 말하면 AI가 화면을 확인하고 git에 저장합니다.

## 6. 얼굴·몸 모양 자체를 바꾸고 싶을 때 (어려움)
얼굴 생김새, 옷 모양(치마·안경 등)은 색이 아니라 **3D 모델을 고쳐야** 합니다. 무료 프로그램 **Blender**(blender.org)를 쓰지만 처음 배우는 데 며칠 걸립니다. 필요하면 AI에게 먼저 "어떤 모양으로 바꾸고 싶다"고 말해 주세요. 무료 에셋 중에서 맞는 것을 찾는 쪽이 훨씬 빠릅니다.
